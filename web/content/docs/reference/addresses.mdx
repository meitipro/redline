## Check the deployment yourself

`scripts/verify.py` reads the source back off the chain with `gen_getContractCode`, compares it byte for byte with `contracts/redline.py`, checks the sha256 against `contracts/FROZEN.json`, and lints the bytes that came back with genvm-lint:

```bash
python scripts/verify.py
```

## The canary seed, measured

The canary comes from data of the judging transaction. Before building on it, a probe contract recorded what `gl.message.raw` carries in a write on this network (`docs/seed-probe.json`): the datetime arrives with microseconds, and no transaction hash is exposed. So the seed is the judging transaction's datetime and sender, the contract address, the attack id and the attack text's hash.

## Add the network to a wallet

The site does this for you. By hand: network name `GenLayer Studio Next`, RPC `https://studio-next.genlayer.com/api`, chain id `61997`, currency `GEN`, explorer `https://explorer-studio-dev.genlayer.com`.

Studio Next charges a fee deposit on every write, from the SDK's estimate; most of it is refunded when the transaction finalizes. Reads are free. The RPC rate-limits each IP, so the site caches shared reads for 20 seconds and drops the cache after each write.
